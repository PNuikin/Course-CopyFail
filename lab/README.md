# Методика экспериментов

Все опыты проводились по единой дисциплине:

1. **Изоляция.** Виртуальные машины связаны только сетью host-only
   (192.168.56.0/24); выход в Интернет включался кратковременно и только
   на время установки инструментов («монтажное окно»), после чего адаптер
   NAT отключался.
2. **Воспроизводимость.** Перед каждым опытом машина откатывалась на
   снимок состояния `vuln-verified` (см. `stand/restore_snapshot.sh`):
   ядро уязвимого диапазона, инструменты установлены, детектор подтвердил
   уязвимость.
3. **Контроль результата.** Успех записи фиксировался поиском 4-байтового
   маркера по точному смещению в файле со случайным содержимым;
   корректность «бесследности» — прямым чтением с диска в обход кэша
   (`O_DIRECT`) и сравнением контрольных сумм и времени модификации.

## Сценарии (каталог `experiments/`)

| Скрипт | Что проверяет |
|---|---|
| `deb_boundary.sh` | карта точности: «запрошенное смещение → фактическое» (0–8000, включая границы страниц) |
| `f2b_ro_fs.sh` | работает ли примитив на ФС, смонтированной read-only (loop ext4) |
| `f2c_immutable.sh` | работает ли примитив против флага immutable (`chattr +i`) |
| `f2d_passwd.sh` | сценарий `/etc/passwd` + самовосстановление файла сбросом кэша |
| `g2_blacklist.sh` | блокировка модуля `algif_aead` → отказ эксплойта на `bind()` |
| `g1_verify.sh` | верификация патченного ядра: детектор, отказ при блокировке, чистый тест ядра, полный сценарий |
| `debian_cycle.sh` | полный цикл на Debian: инструменты, детектор, калибровка, стабильность, LPE |
| `centos_cycle.sh` | полный цикл на CentOS: то же + проверка встроенного algif_aead |

## Предположения сценариев

- на целевой машине настроен `sudo` без запроса пароля для пользователя,
  под которым выполняется опыт;
- в `~/exploit` целевой машины находится **собственная** скомпилированная
  реализация эксплойта и файл-описатель полезной нагрузки —
  в этот репозиторий они не входят;
- для опытов с `/etc/passwd` и `su` используется одноразовая лабораторная
  машина: после каждого прогона машина откатывается на снимок.

## Переменные окружения

Сценарии не содержат учётных данных. При адаптации под свой стенд задайте:

```
export VM_USER=...      # пользователь целевой ВМ
export VM_HOST=...      # адрес ВМ в host-only сети
```
