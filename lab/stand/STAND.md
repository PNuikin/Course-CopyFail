# Испытательный стенд

## Состав

| Машина | Дистрибутив | Ядро | Роль |
|---|---|---|---|
| cf-ubuntu | Ubuntu 24.04.2+ (ISO до мая 2026) | 6.17/6.8 (HWE) | основная цель; algif_aead — модуль |
| cf-debian | Debian 12.9 | 6.1.0-29 | вторая цель; algif_aead — модуль |
| cf-centos | CentOS Stream 9 | 5.14.0-761 | третья цель; algif_aead встроен в ядро |

Ресурсы каждой машины: 2 vCPU, 4 ГБ ОЗУ, диск 40 ГБ. Гипервизор — VirtualBox.

## Сеть

- адаптер 1 — NAT: **только** на время установки («монтажное окно»), затем
  отключается: `VBoxManage modifyvm <ВМ> --nic1 none`;
- адаптер 2 — host-only `192.168.56.0/24`: машины видят друг друга и узел,
  выхода в Интернет нет.

## Порядок развёртывания

1. Создать машину (`VBoxManage createvm/modifyvm/createmedium/storageattach`),
   поставить дистрибутив; сразу отключить автоматическое обновление ядра
   (`unattended-upgrades`).
2. В монтажное окно установить инструменты: `gcc make strace git`,
   клонировать детектор `kwilck/copyfail` и публичный демонстрационный
   эксплойт Theori (для трассировки).
3. Проверить ядро детектором: `sudo bash copyfail/copyfail.sh` —
   ожидать `VULNERABLE` (на RHEL-семействе — учесть, что код встроен).
4. Выключить NAT, снять снимки: `vuln-clean` (инструменты, изоляция)
   и `vuln-verified` (уязвимость подтверждена).
5. Перед каждым опытом — откат: `restore_snapshot.sh` (ниже).

## Автоматическая установка CentOS (kickstart)

VirtualBox 7.1 не поддерживает unattended для RHEL 9, поэтому CentOS
ставился kickstart-файлом, подаваемым по HTTP из строки загрузчика:

```
inst.ks=http://<адрес-узла>:8000/ks-centos9.cfg inst.text ip=dhcp
```

(Tab на пункте меню установщика → дописать параметры → Enter;
Esc прерывает проверку носителя.) Заготовка — `ks-centos9.cfg`
(пароли-заглушки `CHANGE_ME`, SSH-ключ добавьте свой в `%post`).

## Снимок-дисциплина

```
vuln-clean      инструменты стоят, Интернета нет
vuln-verified   уязвимость подтверждена детектором
patched / fixed-kernel / g3-mitigated   состояния после мер защиты
```

Опыт всегда начинается с `VBoxManage snapshot <ВМ> restore vuln-verified`.
